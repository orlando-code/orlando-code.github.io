**esgpull-plus** extends [esgf-download](https://github.com/ESGF/esgf-download) with a YAML-driven API, fast parallel downloads, CDO regridding, and optional surface/seafloor level extraction for CMIP6 NetCDF data.

- **PyPI:** [pypi.org/project/esgpull-plus](https://pypi.org/project/esgpull-plus/)
- **Code:** [github.com/orlando-code/esgpull-plus](https://github.com/orlando-code/esgpull-plus)

```bash
pip install esgpull-plus
```
