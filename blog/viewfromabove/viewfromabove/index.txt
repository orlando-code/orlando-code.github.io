a:T59b,<p>I sometimes think I'm just in it for the maps... <strong>View from Above</strong> is a visualisation side-project built on a fork of – and feeding back into – the incredible library <a href="https://github.com/marceloprates/prettymaps">prettymaps</a>. <a href="https://github.com/marceloprates/prettymaps">prettymaps</a> uses freely-available <a href="https://www.openstreetmap.org/#map=2/-41.2/-6.6">OpenStreetMap</a> data and some custom <a href="https://shapely.readthedocs.io/en/stable/">shapely</a> logic to make gorgeous birds-eye renders.</p>
<p>I've been working on making the visualisation more robust (it can struggle with bridges, large open space, etc.), adding <a href="https://en.wikipedia.org/wiki/Blue_plaque">Blue Plaque</a> indicators for my more nerdy friends, and generally creating cute gifts for friends and family.</p>
<p>If you'd like one for your meaningful neighbourhood, try out the original library (I believe it now ships with an app to make plotting easier) or get in <a href="/contact/">touch</a>!</p>
