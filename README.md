# Website

Welcome to my site!

### Here's what you can find here:

- **Blog System**: Markdown-based blog with automatic parsing and syntax highlighting
- **Contact Page**: Contact form and social media links

### What I used

- **Next.js 14**: React framework with app router
- **TypeScript**: for type-safe development
- **Tailwind CSS**: Utility-first CSS framework for responsive design
- **Markdown**: Blog posts written in markdown with frontmatter
- **Lucide React**: Beautiful, customizable icons

Therefore Node.js 18+ and npm are pre-requisites (installed via `homebrew` because I love Macs). Built with ❤️ using Next.js and Tailwind CSS
